## Configuration surface

`ThemeProvider` accepts:

- `storageKey?: string` — default `laradcs-state`;
- `topnavHeight?: string` — default `4rem`, written to `--topnav-height`;
- `defaults?: Partial<...>` — initial `theme`, `scheme`, and per-side `open`, `pinned`, and `panel` values.

`config/dcs.php` provides the storage key and topnav height used by the Blade pre-paint script (`storage_key` / `DCS_STORAGE_KEY`, default `laradcs-state`; `topnav_height` / `DCS_TOPNAV_HEIGHT`, default `4rem`). Each must match the corresponding `ThemeProvider` prop so pre-paint and React restore the same flat JSON object and the same geometry with no first-paint jump.

The pin breakpoint (960px), per-side percentage model (15% default, 10–100% controls, 200px CSS floor), hamburger positions, and fixed topnav/sidebar geometry are not configurable.

## Scheme naming

dcs.spa calls its classless Ocean scheme `default`. The React port retains the existing `ocean` id; both mean the same classless Ocean token set. Mono and the other scheme ids match directly.

## Deliberate differences

None. The implementation mechanism differs naturally between vanilla DOM code and React state, but the persisted behaviour, defaults, geometry, schemes, carousel motion, content-width modes, and responsive rules are aligned.
